# 自适应布光风格

初版只有白底棚、暗室棚。`library.json` 保存效果目标、针对模型的判断流程和成图检查，不提供固定灯位、灯数或功率。`electron/lighting-styles.cjs` 把文字规则通过现有 Agent 开发指令送达；菜单仅显示名称、简短说明和56px示意图。没有新增模型接口、付费服务或渲染引擎。

Agent 根据本轮模型的尺寸、朝向、材质、主要结构和已有机位安排本机 Blender/C4D 灯光，通过试渲染查看并调整，实际参数保存在本轮脚本或复现记录中。用户明确指令优先；选择风格本身不授权修改模型结构或替换材质。未选风格时沿用语义判断，不强制换棚。

预览来自本地原生渲染，仅用于说明效果方向，未裁切、重绘或冒充当前模型渲染：

- `previews/white-studio.png`：用户已认可的 `lighting-lab/chip-white/v001/review04/blender/chip_white.png`，芯片v003。
- `previews/dark-studio.png`：`projects/第2期/第2期_金块布光.png`，既有暗室芯片样片。

两张示意模型版本与机位不同，不作为“仅改变灯光”的受控实验。图片不含布光参数，不能据此保证所有模型自动达到样片质量；本轮只验证菜单、规则传递和交付兼容性，实际 Agent 的布光结果仍需逐模型查看。
