# 开发与构建

| 目录 | 内容 |
| --- | --- |
| `src` | 可编辑界面、三维预览和开场动画 |
| `electron` | 本地项目、AI 连接、聊天、文件与交付逻辑 |
| `assets` | 自制示例、建模框架、材质、布光、字体与解码器 |
| `scripts` | 构建、打包、示例生成与图标工具 |
| `tests` | 文件保护、关联、交付与连接等回归检查 |
| `examples/dark-metal-chip` | 第三期暗场芯片 C4D 完整案例 |

1.0.0 包含完整可编辑界面、开场、本地项目、AI 连接和三维工作流。数据绘图模块将在后续版本提供。本版只附带第三期暗场金属芯片 C4D 完整案例；Blender 的建模接入仍保留。

## 构建

安装 Node.js 24 或兼容的新版本与 Python 3，执行 README 中的命令。Python 仅用于 Windows 图标与示例辅助处理。查看 GLB 和成图不要求安装建模软件；重新执行本版完整案例需要 C4D。

终端找不到 Python 时，打包前指定 `$env:PYTHON = 'C:\你的Python目录\python.exe'`。`npm ci` 安装锁定依赖，`npm run setup:runtime` 明确安装 Electron 与 esbuild。网络中断时检查网络并重试，不要通过关闭 TLS 校验解决下载问题。

`npm run dev` 只使用 `.local/user-data`。该目录不进入源码包。测试模式的统计只写本地，但真实 AI 连接仍会连接所配置的服务，并不是模拟 AI。

`npm test` 不调用付费模型或真实统计服务。界面验证需要能够运行 Electron 的 Windows 桌面环境。验证记录见 [本地验收](本地验收.md)。

## 可选统计配置

`electron/telemetry-config.json` 已包含官方 PostHog 美国区项目 719835 的公开项目 token，源码运行与官方 Windows 版使用同一配置。首次说明的“同意 / 取消”和设置开关必须保留；没有同意不会上报。开发与界面检查使用 `WORKBENCH_TEST=1`，事件仅写到独立测试用户目录，不发送到云端。字段见 `electron/telemetry-config.example.json`。

自行分发修改版时，替换该文件为自己的项目配置，或将 token 留空关闭统计。也可在仓库外保存自己的配置：

```json
{"host":"https://us.i.posthog.com","token":"phc_YOUR_PUBLIC_PROJECT_TOKEN","projectId":"YOUR_PROJECT_ID"}
```

通过环境变量将它仅注入新包：

```powershell
$env:VL_TELEMETRY_CONFIG = 'C:\你的私人目录\telemetry.json'
npm run package -- --out 'release\my-local-preview'
Remove-Item Env:\VL_TELEMETRY_CONFIG
```

PostHog 将项目 token 定义为可用于客户端的公开凭据，参见 [官方说明](https://posthog.com/docs/feature-flags/installation)。不要使用具有读取 / 管理权限的个人 API key。使用自己的项目，保留选择与撤回入口，并更新发行版隐私说明。统计是同意且成功上报的安装实例，不等于自然人总数或所有下载数。

## 打包与检查

运行 `npm run build`、`npm test`、`npm run test:ui` 后执行 `npm run package`，输出 `release/VisualizationLab-v1.0.0-windows-x64`。已有输出目录不会覆盖。可用 `VL_SMOKE_EXE` 指向打包后的 EXE 再运行 `npm run test:ui`；该检查使用临时项目和临时用户配置，不会向 PostHog 发送事件。项目由 ZHP0226 以个人身份维护。
