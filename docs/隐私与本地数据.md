# 隐私与本地数据

## 本地文件与 AI

项目素材在用户选择的目录中，关联信息在 `.visualization-project.json`。聊天、界面设置、修改意见、连接与统计状态保存在本机用户配置目录。API 密钥使用 Electron 系统安全存储加密保存，具体保护依赖操作系统环境；本机 Agent 可能另有自己的凭据目录。

公开资料不附带作者的账户、私人聊天、个人密钥或历史用户项目。分享自己的配置和备份前，请检查其中内容。

使用 AI 时，输入和相关上下文会交给所选 Agent 或 API，它们可能连接外部模型、记录日志或收费，不能理解为全部 AI 计算都离线。本机原生 Agent 可执行其权限允许的操作，完整访问模式具有相应本机文件与程序权限。

## 可选统计

1.0.0 源码和官方 Windows 版配置了作者的 PostHog Cloud 美国区项目（719835），仅包含用于接收事件的公开项目 token，不包含读取或管理数据的个人密钥。首次说明中提供“同意 / 取消”；取消是不参加且继续使用，也可在设置中改变选择。未同意前不生成用于上报的安装标识、不发事件。

同意后发送首次启动 `workbench_first_open` 和按北京时间每天去重的 `workbench_daily_active`。字段仅含随机安装标识、事件标识和时间、版本、系统平台、活跃日期及测试标记。不会加入聊天、提示词、项目名、文件路径、图片、模型、API 密钥或硬件序列号，未启用自动采集和会话录屏。

现有实现使用 PostHog Cloud 美国区域，禁用地理位置派生，事件的 IP 字段置空。请求仍经过网络服务，这些措施不代表网络层不可见 IP。自行分发修改版时，应替换为自己的项目或清空 token，并同步说明接收方。

网络失败不会阻止创作，事件仅有限排队和重试。关闭统计会中止发送并清空待发队列，不会自动删除此前服务端已接收数据。

随机标识代表本地安装配置：重装 / 清理配置可能产生新标识，同一人的不同电脑也可能计为多个实例；拒绝参与和未成功上报的实例不会计入看板。
