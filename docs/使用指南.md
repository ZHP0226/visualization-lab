# 使用指南 · 1.0.1

可视化实验室面向各种可视化表达。当前版本提供参考、建模、成图与数据绘图，支持对接 Blender 与 Cinema 4D。项目栏分为建模和数据绘图。

## 第一次打开

完整解压便携包，运行 `可视化工作台.exe`。开场播放期间软件进行初始化。在设置中选择浅色 / 深色与字号，按习惯调整面板大小。

先将 `examples/dark-metal-chip` 整个目录复制到自己的工作目录，再用“打开项目”选择其中 `dark-metal-chip-demo` 文件夹。这里已有内容，无需先连接 AI；复制后修改可以保留原例。

## 项目与资源

新建项目时命名并选择位置。项目是真实磁盘目录，隐藏文件 `.visualization-project.json` 记录资源和关联，应与素材一起保留。

参考、模型、成图是三类资源：参考说明目标，模型提供可编辑三维结构，成图是导出的图片。导入后选择模型，可切换结构、成图、参考与对照视图；对照视图保留三者，图片分别支持缩放与拖动。结构树支持部件选择、聚焦与独立显示。

GLB 适合交换完整模型。glTF、OBJ 等格式可能依赖外部文件，需要一起保留，或先导出为 GLB。`.blend` / `.c4d` 是原生工程，交互预览使用导出的通用模型。

## 连接 AI 与软件

打开聊天区域的模型 / 连接选择入口。程序检测本机 Agent；未识别到时，可手动选择程序路径。登录、模型权限和额度由该 Agent 服务管理。

也可新增 API 连接，填写名称、接口地址、密钥和模型，再测试连接。不同服务兼容性可能不同，连接成功不表示所有工具能力都已验证。密钥保存在本机，不要提交个人配置。

需要建模时先安装相应软件，可选 Blender、C4D，也可让 Agent 在操作前检测并询问。本机原生 Agent 能执行其权限允许的本机操作；API 的本机执行能力需要按连接配置启用。先用示例副本体验，重要改动前备份。

## 从参考到成图

1. 建立项目、导入参考并确认关联对象。
2. 描述结构、材质、视角、输出尺寸和要保留的可编辑文件。先做白模确认拓扑，再制作材质。
3. 检查部件、间隙与遮挡，记录需要修改的具体对象。
4. 在对照视图检查交付，保留模型、原生工程与成图。

可复制的请求和完整步骤见 [暗场芯片案例](../examples/dark-metal-chip/README.md)。案例已通过工作台的真实 Codex 对话完成，底层运行随附 C4D 脚本；在线 AI 的输出仍需逐次检查。

## 右击记录局部修改

在三维视图或结构树里右击部件，或在成图、参考图上右击一个位置，填写具体要求后点“完成”。这些意见先保存在聊天区上方的“修改意见”里；可以记录多处，也能点开原意见继续编辑，最后统一点击“发送”交给 AI。右击本身不会直接改动模型或图片。

## 改名、移除与删除

左侧支持右键操作。**改名**同步修改磁盘名称；**移除**仅从当前项目或项目列表中移去，保留原文件；**删除**将文件或项目移入系统回收站。操作前确认对象与范围。

## 保存与迁移

迁移作品时复制完整项目目录，包括隐藏项目文件和依赖。聊天与全局设置默认在当前 Windows 用户的应用数据目录，源码开发模式使用独立 `.local`。不要直接分享整个配置目录，其中可能有对话和连接信息。

浏览本地项目和示例可以离线使用；AI 调用与可选统计按需联网。

## 数据绘图

见 [绘图示例与打开方法](../examples/nature-four-panel/README.md) 和 [README 的绘图步骤](../README.md#数据绘图从模板到一张完整组合图)。新建项目时选择数据绘图；底部模板、期刊和单/双栏选择会写入草稿。同一消息可给 a/b 等分图引用不同模板。生成、导入数据或应用风格前请准备安装了 NumPy、SciPy、Matplotlib、scikit-learn 的 Python，并通过“Python 环境”指定。
